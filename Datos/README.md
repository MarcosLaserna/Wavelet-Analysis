# Datos del proyecto

Esta carpeta reune los datos utilizados a lo largo del proyecto.

## Dataset principal

- `datos_final.xlsx`: dataset consolidado que usa actualmente la app.

## Datasets historicos y complementarios

- `CSI_New_Energy_index.xlsx`
- `DATA revisados Hui.xlsx`
- `eurostat_bonos10.xlsx`
- `eurostat.xlsx`
- `ISE_Clean_Edge_Global_Wind_Energy_index.xlsx`
- `S&P_Global_Clean_energy_index.xlsx`
- `WilderHill.xlsx`
- `Yahoo_Assets.xlsx`

La aplicacion prioriza `datos_final.xlsx` cuando esta disponible. Los demas
archivos se conservan como evidencia de las fuentes y pruebas utilizadas durante
el desarrollo del analisis.
